# 任务需求卡与续访

> Requirements mode: Task Requirement Card, handoff prompt, and resume card formats. Written in Chinese; deliver artifacts in the user's own language.

用于需求访谈模式。需要自我认知地图时使用 [artifacts.md](artifacts.md)。

## Task Requirement Card

使用 Markdown 作为默认可移植成果；只有下游确实需要时才输出 JSON，不虚构某个平台的 API 字段或调度表达式。

卡片不依赖“同上”“你之前指定的来源”等丢失上下文的指代。保留实际来源、时间、范围和排除项；不知道的内容显式记缺口。

下面是裁剪用骨架，花括号表示填入实际材料，不可作为完整规格原样交付：

```markdown
# Task Requirement Card
- 主题：{名称}
- 访谈模式：requirements
- 规格版本：{例如 r1；独立于 Skill 的软件版本}
- 本次交付范围：{完整任务或仅某部分}
- 需求状态：{DRAFT / READY_FOR_REVIEW / CONFIRMED}
- 确认依据：{用户确认的版本/原话，或未确认}

## 目标与验收
{用途、使用者和可观察的合格结果；验收条目可引用需求编号}

## 当前需求
| ID | 维度 | 内容 | 状态 | 依据 |
| --- | --- | --- | --- | --- |
{目标、来源、范围、处理、交付、触发、异常等适用需求}

## 候选补项与排除项
{AI 建议未被接受的项；用户明确拒绝或后续替代的项}

## 未决项
- 阻塞规格：{需要用户选择的内容}
- 可暂缓：{不妨碍本次交付的细节}
- 实施前核实：{所需平台能力、来源可达性等；标明已核实或未验证}

## 执行状态
- 当前授权：{无 / 已授权的具体动作与边界 / 已撤销}
- 实际进度：{未创建 / 已尝试失败 / 已创建及执行结果摘要}
```

“执行结果摘要”指成功返回的任务 ID、时间和设置等结果证明，不包含账号凭证或密钥。记录实际已有的执行结果；单纯写完卡片时应写“未创建”。

关键需求没有证据时写暂定或未知。需求表可将同类已确认细节合并以便阅读，但不同状态不可混写。可暂缓的补项可以留在候选区，不自动进入执行规格。

版本从 r1 开始，发生实质变更才递增；确认跟随具体内容版本。排版修改无需重新确认；用户已明确指示的局部变更可记录该指令作为确认依据，不重问其余字段。

## 交接提示词

用户需要交给另一个 Agent 或实施工具时，可附一段由需求卡派生的执行提示词。它必须保留硬约束、排除项、来源边界、时间语义、输出渠道和重要异常策略。

- 只把已确认和授权默认写成确定要求。
- 暂定或未知写在“开始前需澄清/核实”中，草稿不得伪装成无条件执行指令。
- 按用户本次授权区分“准备配置草稿”和“创建/更新任务”。“已确认需求”本身不等于创建授权。
- 含用户给定来源链接的任务应携带真实清单，不能写“从指定来源抓取”却不提供任何来源。
- 与需求卡逐项核对，不能在改写时丢掉条数上限、严格来源限制、失败通知边界等。
- 跨会话交接时，“当前对话”“这里”等相对目的地仍指原会话。保留已有的可用标识；无法定位时列为待定位项，不默认为接手 Agent 所在的会话。只有用户明确要求迁移目的地时才更新它。
- 不生成伪造的任务 ID、不承诺尚未核实的送达能力。
- 不使用会改变授权范围的模板默认动作。

对于仍有阻塞项的早期卡片，提示词开头应说明“先澄清下列缺口”；若用户只要求卡片，则不必附执行提示词。

## 需求模式 Resume Card

用户暂停、结束或要转移上下文时，给简短续访卡。若刚生成的需求卡已经短而完整，可在末尾补“下一步”作为续访卡，避免重复两份全文。

```markdown
## Interview Resume Card
- 模式：requirements
- 主题与本次交付范围：{内容}
- 规格版本与状态：{rN / 状态}
- 已确认需求及依据：{包括核心来源、范围、时间和排除项}
- AI 候选 / 授权默认：{两者区分，代定权限写明}
- 已否定或被替代：{不应恢复的内容}
- 冲突 / 关键未知：{仍影响交付的内容}
- 可行性核实情况：{当前所知}
- 执行授权与实际状态：{当前会话的授权来源和未/已实施}
- 下一步：{最值得继续的一个方向}
```

来源很多或规格较长时，在续访卡说明需要同时携带完整需求卡；不要只留下另一台设备无法读取的本机路径。不要宣称续访卡是持久存储或跨平台自动同步。用户带回卡片并说继续时，按卡片未决点往下问，遇到新变化只更新受影响部分。
